# India — A Living Canvas

Interactive digital timeline of Indian art, built with React + Vite + Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Build

```bash
npm run build
```

The project is configured for GitHub Pages at:

https://vinaychauhan23.github.io/IndianArtTimeline/

## Publish on GitHub Pages

1. Create a GitHub repository named `IndianArtTimeline` under `vinaychauhan23`.
2. Upload all files from this folder.
3. In GitHub: Settings → Pages.
4. Under Build and deployment, choose GitHub Actions if available, or configure a static Pages workflow.
5. The Vite base path is already configured as `/IndianArtTimeline/`.

## Notes

Artifact images are loaded from Wikimedia Commons URLs. For an academic submission, verify image licensing/attribution requirements and replace any image if a source's terms require it.
